# Cobrador.ai: estudo de caso

Página de portfólio que explica como construí o [Cobrador.ai](https://cobrador.ai), uma plataforma de recuperação de crédito com agentes de IA no WhatsApp, onde sou cofundador e CTO.

**Ver a página:** https://jaysonas55.github.io/cobrador-ai/

O que a página cobre:

- Arquitetura com 17 fluxos em n8n, Supabase (PostgreSQL) e a API oficial do WhatsApp
- Decisões que tornam o agente confiável: cálculo de parcelas fora do LLM, saída estruturada, debounce, transbordo para humano e detector de bots
- Avaliação automatizada do agente, com uma IA atacante contra uma IA juíza

O código do produto é proprietário e não está neste repositório. Aqui ficam só a página e as imagens dela.
